# OfferTrack 校招进度看板

OfferTrack 是一个本地优先的个人求职管理工具，用来记录岗位、招聘阶段、待办事项、面试问题、复盘内容和常用网申信息。

## 立即使用

在线版：[打开 OfferTrack](https://offertrack-campus-2026.stormy-grass-5414.chatgpt.site)

打开后即可使用，不需要注册或登录。在线版与自行部署版都不使用数据库，岗位和个人信息只保存在使用者自己的浏览器中。

## 两种使用方式

| 方式 | 在线版 | 下载源码后本地运行 |
| --- | --- | --- |
| 入口 | 直接打开上面的在线网址 | 在电脑上启动后打开本地网址 |
| 安装 | 不需要 | 需要安装 Node.js 并下载源码 |
| 数据保存 | 当前设备、当前浏览器 | 当前设备、当前浏览器 |
| 数据库 | 不需要 | 不需要 |
| 更新 | 站点更新后自动生效 | 使用者自行下载新版 |
| 使用范围 | 有网络即可打开 | 启动完成后可在本机使用 |
| 控制权 | 依赖公共在线站点持续开放 | 完全由使用者自己掌控 |
| 迁移方式 | 导出 JSON 后在其他环境导入 | 导出 JSON 后在其他环境导入 |

### 在线版的优点与限制

优点：

- 点击网址即可使用，无需安装。
- 所有人可以共用同一个入口，但数据彼此隔离。
- 不需要项目维护者购买数据库。
- 页面更新后，使用者刷新即可获得新版。

限制：

- 数据只存在当前浏览器，换电脑或换浏览器不会自动同步。
- 清除浏览器网站数据后，本地记录可能丢失。
- 在线站点停止服务时，需要改用本地版或其他部署。

### 本地版的优点与限制

优点：

- 使用者自行保存源码并控制运行环境。
- 不依赖公共在线站点持续开放。
- 同样不需要数据库或账号系统。
- 可以自行修改功能和界面。

限制：

- 首次使用需要安装 Node.js、下载源码并启动项目。
- 项目不会自动更新，需要自行获取新版。
- 本地网址与在线网址的数据相互独立，需要通过 JSON 备份迁移。

## 主要功能

- **总览**：查看投递数量、招聘阶段分布、近期待办、待复盘问题和重点岗位。
- **我的投递**：以看板或表格形式管理岗位，记录公司、岗位、地点、优先级、JD、链接和当前阶段。
- **招聘流程**：记录从待投递、笔试、多轮面试到 Offer 或流程结束的阶段变化。
- **待办事项**：创建时间节点，可关联到具体岗位并标记完成。
- **面试复盘**：按问题类型记录面试问题、原始回答、复盘内容、轮次、面试类型和标签。
- **个人信息**：维护基本信息、教育经历、实习经历、项目经历、求职偏好、获奖证书和个人链接。
- **数据备份**：导出或恢复完整 JSON 备份，并可导出 CSV 投递记录。
- **本地存储**：不需要登录、服务器或数据库。

## 使用方法

### 1. 添加岗位

点击右上角“新增岗位”，填写公司名称、岗位名称、阶段、方向、地点、重要程度、投递时间和渠道。岗位链接、JD 与备注可以按需填写。

### 2. 更新招聘进度

在“我的投递”中打开岗位详情，然后修改当前阶段。阶段变化会记录在该岗位的招聘流程中。

### 3. 添加待办

点击“新增待办”，填写标题、日期与时间，并选择是否关联某个岗位。完成后可在总览或岗位详情中查看。

### 4. 记录和复盘问题

点击“记录问题”，选择问题类型，填写问题、面试轮次、面试类型、标签和复盘内容。之后可以在“面试复盘”中继续编辑或删除。

### 5. 维护个人资料

进入“个人信息”，按模块添加基本信息、教育、实习、项目和求职偏好。所有内容只保存在当前浏览器。

### 6. 定期备份

进入“设置 → 数据备份与迁移”：

- “导出完整备份”会下载包含全部记录的 JSON 文件；
- “从备份恢复”可在另一台电脑、另一个浏览器或另一种部署方式中恢复数据；
- “导出投递记录”会生成便于表格查看的 CSV 文件。

## 在自己的电脑上运行

### 环境要求

- Node.js 22.13 或更高版本
- npm（安装 Node.js 时会一并安装）

### Windows 简易启动

1. 下载或克隆本项目。
2. 双击 `start-local.cmd`。
3. 首次启动会自动安装依赖。
4. 根据窗口中显示的地址打开 OfferTrack，通常为 <http://localhost:5173>。

### Windows、macOS 和 Linux 通用方式

```bash
npm install
npm run dev
```

然后打开终端中显示的本地地址。

### 本地生产模式

```bash
npm install
npm run build
npm start
```

根据终端提示打开本地地址。关闭运行窗口只会停止网页服务，不会主动删除浏览器中已经保存的数据。

## 隐私与数据安全

- 新用户首次打开时没有任何预置岗位或个人资料。
- 所有使用数据默认只保存在当前浏览器的 `localStorage` 中。
- 项目不包含账号系统、远程数据库、广告、统计脚本或第三方数据上传。
- 不同浏览器、不同设备和不同网址之间的数据互不相通。
- 清除浏览器数据或卸载浏览器可能导致记录丢失，请定期导出 JSON 备份。
- JSON 和 CSV 文件可能包含个人信息，不要上传到公开仓库或发送给不受信任的人。

更完整的说明见 [PRIVACY.md](PRIVACY.md)。
